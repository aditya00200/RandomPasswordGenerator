# 🔐 Random Password Generator

A simple and secure **Random Password Generator** built using **HTML, CSS, and JavaScript**.  
This web application allows users to generate strong passwords with customizable options and copy them instantly to the clipboard.

---

## 📌 Project Overview

The **Random Password Generator** helps users create secure passwords ranging from **4 to 16 characters**.

Users can generate passwords that include:
- Uppercase letters (A–Z)
- Lowercase letters (a–z)
- Numbers (0–9)
- Special symbols (!, @, #, etc.)

It also includes a convenient **copy-to-clipboard** feature and is fully responsive for both **mobile phones and laptops**.

---

## 🚀 Features

- 🔢 Password length between **4–16 characters**
- 🔠 Includes uppercase letters
- 🔡 Includes lowercase letters
- 🔢 Includes numbers
- 🔣 Includes special symbols
- 📋 One-click copy to clipboard
- 📱 Fully responsive (Mobile & Laptop supported)
- 🎨 Clean and modern UI
- ⚡ Built using pure HTML, CSS & JavaScript

## 🎯 How to Use

1. Select the desired password length (4–16 characters).
2. Choose character types (uppercase, lowercase, numbers, symbols).
3. Click **Generate Password**.
4. Click **Copy** to save the password to your clipboard.
5. Use the generated password wherever needed.
